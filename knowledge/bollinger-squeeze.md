# 布林带收缩突破策略

## 策略原理

布林带由中轨（20日均线）、上轨（+2σ）、下轨（-2σ）组成。当带宽收缩至极窄时（Squeeze），预示即将出现大幅波动。

## 核心信号

- **收缩信号**: 带宽 = (上轨 - 下轨) / 中轨 < 5%，持续3天以上
- **突破确认**: 收盘价突破上轨 → 做多；跌破下轨 → 做空
- **假突破过滤**: 突破当日成交量需大于20日均量的1.5倍

## 参数配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 均线周期 | 20 | 中轨 = SMA20 |
| 标准差倍数 | 2.0 | 上/下轨宽度 |
| 收缩阈值 | 5% | 带宽 < 此值视为收缩 |

## 仓位管理

- 突破当日1/3仓位入场
- 回踩中轨不破加仓1/3
- 止损设在突破K线低点下方0.5%

## 失效条件

- 连续3日回到布林带内
- 成交量萎缩至突破日的50%以下
