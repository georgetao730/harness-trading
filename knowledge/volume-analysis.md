# 成交量分析实战指南

## 量价关系八法则

| 量价关系 | 含义 | 操作建议 |
|----------|------|----------|
| 量增价涨 | 上涨趋势健康 | 持仓或加仓 |
| 量缩价涨 | 上涨动力减弱 | 警惕回调，减仓 |
| 量增价跌 | 抛压增大 | 减仓或离场 |
| 量缩价跌 | 下跌动能衰竭 | 关注底部信号 |
| 量平价涨 | 稳步上涨 | 继续持有 |
| 量平价跌 | 阴跌 | 不建议抄底 |
| 天量天价 | 短期见顶信号 | 果断离场 |
| 地量地价 | 底部区域 | 分批建仓 |

## 突破时成交量的作用

- 有效突破必须伴随成交量放大（≥20日均量1.5倍）
- 缩量突破大概率是假突破
- 突破后回踩缩量 → 有效突破确认

## 特殊量价信号

### 底部放量
- 长期下跌后突然放量上涨 → 主力建仓信号
- 连续3日放量 > 均量2倍 → 底部确认

### 顶部缩量
- 高位缩量横盘 → 出货信号
- MACD顶背离 + 缩量 → 强烈看空

### 对倒放量
- 开盘巨量但价格不动 → 警惕主力对倒
- 尾盘突然放量拉升 → 次日大概率低开

## 成交量指标

- **OBV（能量潮）**: OBV与价格同步新高 → 趋势延续
- **VWAP（成交量加权均价）**: 价格在VWAP上方 → 多头占优
- **换手率**: >5%日换手 → 活跃度高，适合短线
