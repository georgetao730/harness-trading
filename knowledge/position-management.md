# 仓位管理基础框架

## 核心原则

仓位管理是交易系统中最重要的组成部分。一条铁律：**单笔亏损不超过总资金的2%**。

## 凯利公式简化版

```
仓位比例 = 胜率 - (1 - 胜率) / 盈亏比
```

示例：胜率40%，盈亏比3:1
→ 仓位 = 0.4 - 0.6/3 = 0.2 = 20%

## 金字塔加仓法

| 阶段 | 仓位占比 | 条件 |
|------|----------|------|
| 初始建仓 | 30% | 信号首次触发 |
| 第一次加仓 | 30% | 盈利5%以上且回踩支撑 |
| 第二次加仓 | 25% | 盈利10%以上 |
| 机动仓位 | 15% | 盘中T+0机会 |

## 风险控制规则

1. 单一标的最大持仓 ≤ 总资金30%
2. 同一板块合计 ≤ 总资金50%
3. 日内总交易次数 ≤ 5笔
4. 连续亏损3笔 → 当日停止交易
5. 日内亏损触及3% → 强制平仓

## 动态仓位调整

- 账户盈利每增加10%，单笔风险可提升至2.5%
- 账户亏损每增加5%，单笔风险降至1.5%
- 最大回撤超过15% → 暂停交易一周
